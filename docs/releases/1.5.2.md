# Heimdall 1.5.2

Changes since 1.5.1:

## Evaluation and search

- Switch to the Remiel NNUE network, with an evaluation scale of 282.
- Fix root-move filtering and deduplication for `searchmoves`, and correctly
  restrict MultiPV searches to the requested legal root moves.
- Fix UCI search-completion handling so a queued completion cannot unblock a
  later search's `wait` command.

The default depth-13 benchmark is **5,611,448 nodes** with the bundled Remiel
network. This is a correctness reference, not a playing-strength measurement.

## Terminal UI

- Watch external UCI engines with separate commands and options for each color.
  Show their names, scores, PVs and search statistics, and include engine details
  in exported PGNs.
- Recover external engines in watch mode and keep the evaluation panel stable
  between turns. Correct the built-in Black engine's displayed search information.
- Display PVs in SAN by default, with `:set pvnotation uci` available to switch
  back. Correct castling notation for standard chess and Chess960.

See the [TUI guide](../TUI.md) for commands and supported terminals.

## Android and browser support

- Add standalone Android UCI executables for ARM64 and x86-64, with embedded
  weights, runtime SIMD selection, API 21 support and 16 KiB page alignment.
- Add a WebAssembly build with SIMD and shared-memory search threads.
- Add Wasmdall, a browser interface for play and analysis with clocks, engine
  controls, position imports, move history and PGN export, plus a UCI console.

See the [Android](../ANDROID.md) and [browser](../WASM.md) guides for setup.
Browser builds are built from source separately from the downloadable executables.

## Downloads and builds

Desktop release binaries now use profile-guided optimization, including both
architecture slices in the combined Linux and macOS executables. Android uses
optimized NDK/LTO builds.

Choose the archive for your system:

| System | Archive |
| --- | --- |
| Linux, Intel/AMD or ARM64 | `heimdall-1.5.2-linux-universal.tar.gz` |
| Linux, Intel/AMD standalone fallback | `heimdall-1.5.2-linux-amd64-universal.tar.gz` |
| Linux, ARM64 standalone fallback | `heimdall-1.5.2-linux-arm64-universal.tar.gz` |
| Windows, Intel/AMD | `heimdall-1.5.2-windows-amd64-universal.zip` |
| macOS, Intel or Apple Silicon | `heimdall-1.5.2-macos-universal.tar.gz` |
| Android, ARM64 | `heimdall-1.5.2-android-arm64-universal.tar.gz` |
| Android, x86-64 | `heimdall-1.5.2-android-amd64-universal.tar.gz` |

Each target also offers its executable directly and a `.sha256` checksum file.
Direct Linux and macOS downloads may need `chmod +x` before use. The combined
Linux executable extracts into a private runtime cache; use the standalone
fallback for your CPU if your GUI cannot run the launcher.

All downloads require a 64-bit system. macOS requires version 11 or later;
Android requires 5.0 (API 21) or later and an app that supports external engines.
See the [installation guide](../BUILDING.md) and
[release build guide](../RELEASES.md) for details.
